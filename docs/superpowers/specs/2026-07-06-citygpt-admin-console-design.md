# CityGPT 管理後臺 Prototype 設計

## 目標

在現有 CityGPT 藍白視覺與元件語言上，新增一套可操作的管理後臺 Prototype。使用本地模擬資料呈現權限治理、知識生命週期、稽核追蹤、使用 KPI 與回饋處理；不連接正式 API，也不執行真實帳號、文件或資料變更。

## 導覽與角色

後臺使用固定側欄，包含以下五個主頁：

1. 使用者與權限
2. 文件與知識庫
3. 稽核日誌
4. 使用統計
5. 回饋管理

頂部顯示目前角色與單位。Prototype 提供「系統管理員、知識管理員、稽核人員、分析人員」角色切換，切換後更新導覽可見性與按鈕可用狀態，讓權限差異能直接驗收。

## 共通互動

- 全域搜尋、頁面標題、資料更新時間與管理者帳號。
- 桌面使用側欄與內容區；手機使用可開合導覽。
- 表格提供搜尋、篩選、排序、分頁狀態與空狀態。
- 詳情以右側抽屜呈現，建立與高風險操作使用對話框。
- 成功、錯誤與權限不足均有可讀提示；不只依靠顏色。
- 所有破壞性操作顯示影響範圍並要求明確確認。
- 主要按鈕、表單、抽屜、對話框與篩選控制皆可操作。

## 1. 使用者與權限管理

### 列表

- 欄位：姓名、Email、單位、角色、帳號狀態、最後登入、操作。
- 搜尋姓名或 Email；依單位、角色、狀態篩選。
- 狀態使用「啟用、停權、邀請中」，同時顯示文字與圖示。

### 操作

- 新增使用者：姓名、Email、單位、角色，送出後加入本地列表。
- 使用者詳情抽屜：基本資料、登入紀錄、已套用角色、有效權限。
- 編輯角色：以權限矩陣呈現「使用者、知識庫、稽核、統計、回饋」的檢視／管理權限。
- 停權：確認對話框顯示使用者、影響與可恢復說明。
- 權限不足時禁用操作並解釋原因。

## 2. 文件與知識庫管理

### 列表

- 欄位：文件名稱、知識庫、分類、版本、可見範圍、上架狀態、索引狀態、更新時間、操作。
- 篩選：知識庫、分類、上架狀態、索引狀態、可見範圍。
- 索引狀態固定為「待處理、索引中、已完成、失敗」。

### 操作

- 上傳文件對話框：檔案名稱、知識庫、分類、可見範圍與上架設定；使用模擬檔案資訊，不上傳真實檔案。
- 文件詳情抽屜：版本歷程、權限、索引摘要、最後操作人。
- 上架／下架：確認對話框顯示會影響哪些使用者。
- 重建索引：由待處理進入索引中，再以短暫模擬完成；失敗項目提供重試。
- 分類與可見範圍可在抽屜中調整，並在儲存後更新列表。

## 3. 稽核日誌

### 原則

- 日誌為唯讀，不提供修改或刪除。
- 每筆事件保留時間、操作者、來源 IP、資源、動作、結果與追蹤 ID。

### 操作

- 搜尋操作者、資源或追蹤 ID。
- 依時間、模組、動作、結果篩選。
- 詳情抽屜顯示變更前後內容、權限判斷與相關事件。
- 匯出按鈕只顯示模擬成功提示，不產生真實敏感檔案。

## 4. 使用統計

- KPI：今日提問數、月活躍使用者、回答成功率、平均回應時間。
- 時間範圍：近 7 天、30 天、90 天。
- 使用量趨勢以可讀資料表與原生 progress 呈現，避免虛構精密圖表。
- 熱門知識庫、單位使用排行、無答案問題比例與系統錯誤摘要。
- 點選 KPI 或排行項目會更新右側說明區，展示指標定義與數據來源。

## 5. 回饋管理

### 列表

- 欄位：回饋情緒、問題摘要、使用者單位、來源知識庫、標籤、處理狀態、時間。
- 篩選：正向／負向、狀態、知識庫、標籤。
- 頁首顯示正向回饋率、待處理數與本週變化。

### 操作

- 詳情抽屜顯示問題、AI 回答、引用來源、使用者意見與對話脈絡。
- 可新增標籤、指派處理人、更新為「待處理、處理中、已完成、忽略」。
- 完成處理時需填寫處理註記，更新後同步反映在列表與 KPI。

## Prototype 資料與狀態

- 所有資料固定於前端本地 state；重新整理可恢復預設樣本。
- 使用寫實的雲林縣府／CityGPT 範例，不包含真實個資或機密資料。
- 每個頁面包含正常、空、處理中、錯誤或權限不足的可切換示範狀態。
- 角色切換、篩選、對話框、抽屜、狀態更新與確認流程均可點擊。

## 技術與檔案邊界

- 延伸現有 React、TypeScript、Vite Prototype。
- 將目前大型 `App.tsx` 的新管理後臺功能拆成 `admin` 領域型別、樣本資料、版面元件與五個頁面，避免持續堆入單一檔案。
- 現有 AI 任務排程頁保留，管理後臺以新入口切換，不破壞既有互動。
- 使用 Lucide 圖示與現有 CSS tokens；不使用 emoji、手繪 SVG 或無標籤圖示取代正式 UI。

## 驗收條件

- 五個頁面均可從側欄進入，桌面與手機不產生橫向溢位。
- 角色切換會改變至少一組可見導覽與操作權限。
- 使用者新增、角色編輯與停權可完成完整確認流程。
- 文件上架／下架、分類權限與索引狀態可操作。
- 稽核日誌保持唯讀，詳情含變更前後與追蹤 ID。
- 統計頁能切換時間範圍並說明 KPI 定義。
- 回饋可指派、標記、完成並更新正向回饋率或待處理數。
- 所有模擬寫入均明確標示為 Prototype，不會觸發真實後端。
- 自動測試涵蓋導覽、權限、文件狀態、稽核唯讀與回饋處理主流程。
